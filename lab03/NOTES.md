git restore - восстанавливает файл из последнего коммита (HEAD). Текущие несохраненные правки будут полностью перезаписаны версией из последнего коммита
git restore - восстанавливает файл из определенного коммита в прошлом. Текущие правки также заменятся версией файла из указанной точки

Отличие git revert от git reset --hard
git reset --hard - физически удаляет коммиты из истории и затирает файлы.
git revert создает новый коммит, отменяющий изменения старого, не трогая историю

git reset --hard изменяет прошлую историю, что ломает репозитории других разработчиков, если они уже успели скачать эти коммиты. `git revert` безопасен, так как он добавляет новый коммит в будущее, что исключает конфликты при совместной работе

Ветка — динамический указатель. Она двигается вперед автоматически с каждым новым коммитом. Используется для постоянного написания кода

Тег — статический указатель. Он жестко закреплен за одним конкретным коммитом и не перемещается при добавлении новых изменений. Используется для маркировки версий и релизов
