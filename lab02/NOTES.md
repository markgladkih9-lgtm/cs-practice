
Рабочая папка - папка проектов на компьютере, в ней открываются файлы и пишется код
Индекс - промежуточные файлы, которые отправляются перед сохранением. Пример: из пяти коммитов нужно отправить только два
Коммит - содержит точные данные из индекса на момент фиксации

Git — программа для управления версиями кода на компьютере
Github - облачная программа для хранения проектов в интернете и совместной работы

git diff — это разница между написанным на компьютере и подготовленным к коммиту
git diff --staged — это разница между подготовленным и прошлым коммитом



git status — показывает, какие файлы изменены, удалены или не отслеживаются
git diff — показывает изменения, которые еще не добавлены через git add
git diff --staged — показывает изменения, подготовленные к коммиту




Ветка — это указатель на один из коммитов,позволяющий изолированно работать над новой функцией или исправлением ошибки, не меняя основной код
При новом коммите текущая активная ветка автоматически сдвигается вперед, указывая на самый свежий снимок кода 
Слияние — это процесс объединения изменений из одной ветки в другую
